Getting Started

Integration Workflow

Three steps to go live with your TCE ERP integration.

1
Request Credentials

Contact the TCE integration team to receive your organization's Basic Token and target environment details.

2
Obtain Bearer Token

Call the School Login API with your Basic Token to receive a Bearer Token for all subsequent calls.

3
Call Integration APIs

Use your Bearer Token across Teacher Login, Academic Year Setup, and other modules. Re-authenticate when the token expires.
